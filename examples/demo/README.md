# Known-sequence example

The reference is 6,000 bp. `sample0` follows the reference; `sample1` and
`sample2` carry the edits in `truth.tsv`; `reverse` is the reverse-complement
walk of the changed sequence. The truth uses 0-based, half-open intervals;
`-` denotes an empty ALT (deletion). It is an independent input description,
not a table generated by PathAllele. An unused ambiguous node is also present.
