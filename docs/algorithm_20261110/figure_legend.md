**a, Occurrence-aware complete-allele extraction.** A short synthetic example illustrates an inverted sequence component accompanied by a flanking TT-to-AC substitution. The reference core AGTC–CCGA becomes TCGG–GACT, its reverse complement. Rectangular sequence nodes and curved links depict two forward-oriented paths; the graph need not encode the difference as reverse traversal of shared nodes. PathAllele maps full path sequences to a linear reference with minimap2 and combines mapping with oriented node occurrences to resolve source intervals. The shared GGA node illustrates reference/query visits at positions r/q; a node ID alone is not a physical coordinate. Black flanks abstract eligible anchors shared by all maximum-score candidate chains after source and uniqueness filtering. The complete local sequence is retained before event projection. Crossed links relate reverse-complementary sequence blocks, whose arrows indicate orientation relative to the reference, not the direction in which printed bases are read. A general sequence classifier can recognize an inverted component with additional changes as INV_COMPLEX even when the native source class is SEQUENCE. Normalization and sequence replay constrain event representation; unresolved calls remain missing. The short bases illustrate sequence relationships only: they are below the default 31-bp evidence threshold and are not an executable caller fixture. The example is inspired by the structural pattern of oriP, without reproducing its sequences, coordinates or length. Reference-FASTA validation, bounded graph-only supplementation and conditional vcflib/WFA2 projection are omitted for clarity. Complete alleles, replay and missingness are not exclusive to PathAllele; the illustrated method combines them with graph-path occurrence evidence.
