# PathAllele algorithm panel a

[Current PDF](PathAllele_panel_a.pdf): 180 × 58.5 mm. Editable sources:
`PathAllele_panel_a.vectorcraft` and `PathAllele_panel_a.svg`.

The figure uses a short synthetic inversion plus substitution, not the real oriP
sequence. Its drawing-scale bases are below production evidence thresholds.

Rebuild with the [official VectorCraft CLI 0.23.0](https://github.com/storytold/vectorcraft/releases/tag/v0.23.0):

```sh
python3 export_source_resolved.py --cli /path/to/vectorcraft-cli
```

`build_source_resolved.py` creates the SVG; `export_manifest.json` records the
exporter and output hashes. No desktop application state is required.
